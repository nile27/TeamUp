# DESIGN.md — 디자인 시스템

사이드프로젝트 매칭 플랫폼의 디자인 기준 문서. 랜딩과 앱 내부의 톤이 다르므로 분리해서 정의한다.

---

## 0. 핵심 원칙

- **랜딩 = 화려하게, 앱 내부 = 담백하게.** 두 영역은 목적이 다르므로 톤을 분리한다.
- 두 영역을 하나의 브랜드로 묶는 공통 요소: **앰버 포인트 컬러 + Pretendard + 따뜻한 먹 텍스트(#2B2620)**.
- 랜딩은 커스텀 마크업 중심(shadcn 거의 안 씀), 앱 내부는 shadcn 기반.

---

## 1. 컬러 팔레트

### 브랜드 (공통)
| 이름 | HEX | 역할 |
|------|-----|------|
| Amber | `#FFA940` | 포인트 · 버튼 · 강조 · 활성 상태 |
| Amber Deep | `#F08C00` | 호버 · 진한 강조 |
| Amber Soft | `#FFF4E3` | 옅은 배경 블록 |
| Ink | `#2B2620` | 본문 텍스트 (순검정 대신 따뜻한 먹) |
| Ink Soft | `#6B6257` | 보조 텍스트 |
| Canvas | `#FFFFFF` | 기본 배경 |

### 랜딩 섹션 색 블록 (파스텔, 저채도)
| 이름 | HEX | 용도 |
|------|-----|------|
| Sky | `#EAF4FB` | Hero 등 |
| Amber Soft | `#FFF4E3` | Problem, Highlight 등 |
| Peach | `#FDEEE6` | Flow 등 |
| Mint | `#EAF6EF` | Participation 등 |
| Footer Ink | `#2B2620` | 푸터 (유일한 어두운 영역) |

### 앰버 사용 규칙 (중요)
- 앰버는 밝은 색이라 흰 배경 위 **텍스트로 쓰면 대비가 약함** → 글자색으로 쓰지 말 것.
- 앰버는 **버튼 배경 · 아이콘 · 밑줄 · 색 블록**으로만 사용.
- 앰버 버튼 위 글자는 `#2B2620`(진한 먹)으로. 흰 글자 금지.

---

## 2. 타이포그래피

- **폰트**: Pretendard (한글). 영문 헤드라인은 굵은 산세리프.
- **패턴**: 영문 대문자 헤드라인 + 한글 서브 (UTO 스타일). 예: `FLOW` 크게 + "아이디어가 팀이 되기까지" 아래.
- **위계**: 크기 + 굵기 둘 다 활용 (랜딩은 큼직하게 대비).

| 역할 | 크기 | 굵기 | 용도 |
|------|------|------|------|
| Hero | 56px | 800 | 랜딩 메인 헤드라인 |
| Section Eng | 48px | 900 | 영문 섹션 타이틀 |
| Section KR | 32px | 800 | 한글 섹션 헤드라인 |
| Body | 18px | 400 | 본문 |
| Caption | 14px | 400 | 보조 설명 |

앱 내부는 이보다 작게 (본문 14~16px 중심, 밀도 있게).

---

## 3. 랜딩 페이지 구조 (레퍼런스: UTO 스타일)

섹션마다 배경색을 바꿔 리듬을 준다. 각 섹션에 Storyset 일러스트 1개.

| # | 섹션 | 배경 | 내용 | 일러스트 |
|---|------|------|------|----------|
| 1 | Hero | Sky `#EAF4FB` | "개발 못 해도, 기획자로 참여하세요" + 서브 + 버튼 2개 | 두 사람 협업/악수 (연결) |
| 2 | Problem | Amber Soft | 좌우 대비: "아이디어 있는데 만들 사람이?" vs "만들 실력 있는데 뭘?" | 고민하는 인물 2명 |
| 3 | Flow | Peach | 4단계: 커뮤니티 → 반응 → 정식 모집 → 팀 결성 | 단계별 흐름 (왼→오) |
| 4 | Participation | Mint | 3카드: 개발자 모집 / 기획자 모집 / 커뮤니티 | 역할별 인물 |
| 5 | Planner Highlight | Amber Soft | "개발 지식 없어도 됩니다. 문제정의·기획·QA로 참여" + CTA | 기획하는 인물 |
| 6 | Final CTA | White / 옅은 앰버 | 회원가입 유도 + 앰버 버튼 | — |
| 7 | Footer | Ink `#2B2620` | 서비스명 · 링크 · 카피라이트 | — |

한국어. 원페이지 세로 스크롤. 은은한 스크롤 fade-in (Framer Motion, 해당 컴포넌트만 `'use client'`).

> **참고**: 섹션 4색이 너무 알록달록하면 옅은 앰버/화이트 번갈아 단색 톤으로 절제 가능. 실제 화면 보고 판단.

## 4. 일러스트 가이드

- **소스**: Storyset (Freepik). 사람 캐릭터 라인 일러스트. 상업적 무료(출처 표기).
- **색 통일**: 모든 일러스트 강조색을 앰버 `#FFA940`로 맞춤 (Storyset 색 커스텀). → 통일감의 핵심.
- **스타일**: 라인(rounded) 스타일 선택.
- **배치**: 섹션당 1개, 인물이 "뭔가 하는 장면"(협업/고민/기획/발표).
- **포맷**: 투명 배경 PNG 또는 SVG로 받아 색 블록 위에 얹기.

일러스트가 이 스타일의 심장. 없으면 색 블록만 남아 밋밋해짐.

---

## 5. 앱 내부 (커뮤니티 · 모집 · 대시보드)

- **기반**: shadcn/ui + Tailwind. 담백하고 기능적.
- **배경**: 화이트 중심. 랜딩 같은 색 블록 없음.
- **앰버**: 포인트로만 유지 — 주요 버튼, 활성 탭(선택된 필터), 기획 완성도 게이지, 링크 강조.
- **활성 상태**: 선택된 필터 탭 등은 앰버 배경 + 진한 먹 텍스트, 또는 진한 먹 배경 + 흰 텍스트 중 택1로 통일.
- **radius**: 버튼 8px, 카드 12px (shadcn 기본에서 크게 벗어나지 않게).
- **그림자**: 최소화. 구분은 여백과 옅은 테두리로.
- **밀도**: 랜딩보다 촘촘하게. 목록·폼은 정보 밀도 우선.

---

## 6. 컴포넌트 톤 메모

- **버튼(primary)**: 앰버 배경 `#FFA940` / 텍스트 `#2B2620` / radius 8px.
- **버튼(secondary)**: 투명 배경 / 먹 테두리 / 먹 텍스트.
- **카드**: 흰 배경 / 옅은 테두리 / radius 12px / 그림자 없음.
- **뱃지(모집 유형 등)**: 옅은 앰버 배경 + 먹 텍스트, 또는 먹 배경 + 흰 텍스트.
- **완성도 게이지**: 앰버로 채워지는 프로그레스 바.
- **입력 필드**: 흰 배경 / 옅은 테두리 / 포커스 시 앰버 테두리.

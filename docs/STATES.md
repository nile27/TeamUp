# STATES.md — 상태 & 폼 검증

모든 데이터 화면은 정상 상태만 만들지 말 것. 빈/로딩/에러를 반드시 처리. 폼은 검증 필수.

---

## 1. 목록 페이지 3가지 상태

모든 목록(커뮤니티/모집/대시보드)에 필수:

- **빈 상태**: 안내 문구 + 다음 행동 유도 버튼 (그냥 "데이터 없음" 금지)
- **로딩**: 스켈레톤 (스피너보다 스켈레톤 선호)
- **에러**: 안내 + "다시 시도" 버튼

---

## 2. 화면별 빈 상태 문구

| 화면 | 메시지 | 액션 |
|------|--------|------|
| `/community` | 아직 글이 없어요. 첫 아이디어를 남겨보세요. | 글쓰기 |
| `/recruit` | 아직 모집이 없어요. 첫 모집을 등록해보세요. | 모집 등록 |
| 필터 결과 0 | 조건에 맞는 결과가 없어요. 필터를 바꿔보세요. | 필터 초기화 |
| 대시보드/내 모집 | 아직 등록한 모집이 없어요. | 모집 등록 |
| 대시보드/지원한 모집 | 아직 지원한 모집이 없어요. 둘러볼까요? | 모집 보기 |
| 댓글 | 첫 댓글을 남겨보세요. | — |

## 3. 폼 검증 규칙

에러 표시: 필드 테두리 빨강 + 아래 빨간 메시지. 제출 시 전체 + 블러 시 해당 필드. **타이핑 중엔 에러 안 띄움.**

| 폼 | 필드 | 규칙 | 에러 메시지 |
|----|------|------|-------------|
| 로그인 | 이메일 | 필수·형식 | 올바른 이메일 형식이 아니에요 |
| 로그인 | 비밀번호 | 필수 | 비밀번호를 입력해주세요 |
| 회원가입 | 이메일 | 필수·형식·중복(서버) | 이미 가입된 이메일이에요 |
| 회원가입 | 닉네임 | 필수·2~20자 | 닉네임은 2자 이상이에요 |
| 회원가입 | 비밀번호 | 필수·8자 이상 | 8자 이상 입력해주세요 |
| 모집 작성 | 유형 | 필수 선택 | 유형을 선택해주세요 |
| 모집 작성 | 제목 | 필수·5~60자 | 제목을 입력해주세요 |
| 모집 작성 | 설명 | 필수·10자 이상 | 설명을 조금 더 작성해주세요 |
| 모집 작성 | 역할 | 최소 1개 | 최소 1개의 역할이 필요해요 |
| 커뮤니티 작성 | 말머리 | 필수 선택 | 말머리를 선택해주세요 |
| 커뮤니티 작성 | 제목·내용 | 필수 | 제목과 내용을 입력해주세요 |
| 댓글 | 내용 | 필수·1자 이상 | 댓글을 입력해주세요 |

---

## 4. 검증 구현

- **라이브러리**: react-hook-form + zod (shadcn Form 기본 지원)
- **이중 검증**: 클라이언트(즉시 피드백) + 서버 Action(신뢰). zod 스키마를 feature의 `schema.ts`에 두고 양쪽 공유
- **타이밍**: 제출 시 전체 + 블러 시 해당 필드. 타이핑 중엔 에러 안 띄움
- **표시**: 필드 테두리 빨강 + 아래 빨간 메시지 (shadcn `FormMessage`)
- **서버 에러**(중복 이메일 등): Server Action 결과를 `useActionState`로 받아 필드에 표시
- **제출 중**: 버튼 비활성 + 로딩 (`useFormStatus`)

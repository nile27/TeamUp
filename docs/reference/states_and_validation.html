5 · 검증 구현 메모
• 라이브러리: react-hook-form + zod (shadcn Form이 이 조합 기본 지원)
• 이중 검증: 클라이언트(즉시 피드백) + 서버 Action(신뢰). zod 스키마를 lib/에 두고 양쪽 공유
• 타이밍: 제출 시 전체 검증 + 블러(포커스 아웃) 시 해당 필드. 타이핑 중엔 에러 안 띄움(짜증남)
• 표시: 필드 테두리 빨강 + 아래 빨간 메시지. shadcn FormMessage 사용
• 서버 에러(중복 이메일 등): Server Action 결과를 useActionState로 받아 해당 필드에 표시
• 제출 중: 버튼 비활성 + 로딩 (useFormStatus)
이 문서로 목록 3상태(빈/로딩/에러) + 폼 검증이 확정. Claude Code에 주면 정상 상태만 만드는 실수를 방지. zod 스키마는 lib/에 두고 클라·서버 공유가 핵심.

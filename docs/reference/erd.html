관계 (Relationships)

User 1 — N CommunityPost 한 유저가 여러 커뮤니티 글 작성
User 1 — N Recruit 한 유저가 여러 모집글 작성
User 1 — N Application 한 유저가 여러 모집에 지원
Recruit 1 — N RecruitRole 한 모집이 여러 역할을 구함 (프론트 1명 + 디자이너 1명…)
Recruit 1 — N Application 한 모집에 여러 지원자
CommunityPost 1 — 1 Recruit 🌱 승격 다리 — 커뮤니티 글이 정식 모집으로 발전 (promotedFrom, 선택적 1:1)
핵심 축 — 가운데 Recruit가 허브. User가 작성하고, RecruitRole로 역할을 나누고, Application으로 지원이 붙고, CommunityPost에서 승격돼 들어옴. 이 네 방향 연결이 서비스의 데이터 흐름 전체예요.
